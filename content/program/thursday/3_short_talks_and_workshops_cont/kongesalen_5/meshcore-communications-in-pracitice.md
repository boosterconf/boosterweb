I'll be starting off with a quick intro to what MeshCore is (Lora-based texting), how it works, and an overview of the current state of the mesh in Bergen/Norway.
After the into I'll lend out some devices that people can use for talking on the local mesh. Then walk around helping people talk on the mesh and answer questions.
In the background I'll have a live stream of the data using tools like https://corescope.eth0.no/ 
If time allows I can show simplified signal propagation and how to plot repeater routes using topographic maps and signal tools.

Tools needed by audience: Android or iPhone
