Python is great at scraping data from the web, why don't we make a cookbook to save all our favorite recipes? Inspired by a small side project I built for my potluck group, I'd like to show everyone how to use FastAPI, Python, and Github to make a blog that automatically updates when you email a recipe to a secret email address. Attendees will leave with a working project that makes use of Python, Github Actions (and the Github API) and all free tools/hosting; the project can be extended in lots of ways and you are limited only by your imagination :)
