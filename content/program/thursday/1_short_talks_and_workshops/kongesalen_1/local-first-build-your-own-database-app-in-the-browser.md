Did you know that all modern browsers have a built-in object database where you can store gigabytes of data, including blobs? Did you know it supports transactions, fast indexes, and schema migrations out of the box?

Local-first applications turn the traditional web architecture on its head. Instead of sending every operation to a server, the database lives directly in the browser, making applications fast, resilient, and available even when the network isn't. Perfect for mobile apps out in the real world, but also surprisingly useful for huge form-based, multi-step wizards where losing state is not an option!

In this workshop, we'll build a local-first database application from scratch. We'll create a schema, evolve it through migrations, build queries using indexes, and hook everything up with live UI updates.

We'll be using TypeScript, React and Dexie, so bring your favourite editor and get ready to use your own hands to make something!

The browser is not just for the frontend - come see what happens when it becomes your database too!
