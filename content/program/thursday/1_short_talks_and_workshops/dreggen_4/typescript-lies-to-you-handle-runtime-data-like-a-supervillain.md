TypeScript gives you a wonderful feeling of safety. Then your code hits production, an API returns null where you expected a string, and everything falls apart. The compiler didn't lie on purpose. It just doesn't exist at runtime, and JSON.parse returns the infamous any type.

This is a hands-on workshop about validating runtime data with Zod v4. You'll work through 18 interactive exercises in a purpose-built, Superman-themed web app:

JSON Lab: craft payloads against real Zod-validated API endpoints and learn to read the errors that come back.

Schema Lab: write schemas from scratch, evaluated live against test cases.

Form Lab: build per-field and cross-field validation for real HTML forms, including transforms, enums and superRefine.

Exercises unlock sequentially, progress is saved, there are lots of achievements to be earned and you can unlock a fancy PDF certificate at the end. 

Bring a laptop with a browser and your best villainous laugh.
