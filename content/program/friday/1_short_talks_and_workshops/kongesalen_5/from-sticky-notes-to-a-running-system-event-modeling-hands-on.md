Most teams design on whiteboards and then watch the code drift away from the design. In this workshop we go from an empty canvas to a working event-sourced application in one session. We start with event brainstorming for a realistic domain. Then we lay it out as an Event Model: a timeline of commands, events and read models. We slice it into small parts and write each slice as a Given/When/Then spec. Then we build those slices, add a new read model by replaying history, and see what it's like to keep a system's full story instead of only its latest state. To finish, we give one fully specified slice to an AI coding agent and look at why a precise model gets far better results from it than a vague prompt. Bring a laptop. You'll leave with a method you can use on Monday, whatever stack you work in.
