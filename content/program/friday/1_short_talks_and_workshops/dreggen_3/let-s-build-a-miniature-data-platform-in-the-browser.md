Working with data is way too much fun to leave to the data engineers alone. We will write a teeny-tiny script to capture events in the browser. Next we need to store and reshape the raw data by writing SQL to make a data model. And finally we will visualise the data with a chart. All using as little technology as we can get away with: HTML, JavaScript, DuckDB-Wasm, SQL and SVG. Our goal is to understand how a data platform works, by shrinking concepts down to something so small that they fit in a browser. This workshop is for anyone who codes and you will build your own project that ingests, models and visualises data. Bring a laptop and an editor!
